1송출 방법 고르기 (둘 중 하나)
A. 스테레오 믹스

설치 없음 · 대신 PC 소리(게임·디스코드)도 같이 나가요

  1. Win+R → mmsys.cpl → [녹음] 탭
  2. 빈 곳 우클릭 → 사용 안 함 장치 표시
  3. 스테레오 믹스 우클릭 → 사용 → 이 창 새로고침(F5)
  4. 헤드폰은 메인보드 단자(Realtek)에 꽂기

⚠ "기본 장치로 설정"은 누르지 마세요 (아래 ②에서 "기본 통신 장치"로 정해요)

마이크·송출·헤드폰을 이 PC에 맞게 한 번에 골라 줘요.

송출 방식
🎙 마이크
📡 송출 (보통 CABLE Input)
🎧 헤드폰
내 목소리 듣기헤드폰으로 내 목소리도 들려요

지연을 줄이려면 블루투스 대신 유선 헤드폰을 쓰고, 마이크와 헤드폰의 샘플레이트를 같게(예: 48000Hz) 맞추세요. 스피커를 쓰면 하울링이 날 수 있어요.

문제 해결
  • 팀원에게 안 들림: 오버워치 음성 대화 장치가 "대화 장치"인지, Windows 녹음 탭에서 CABLE Output(또는 스테레오 믹스)이 "기본 통신 장치"인지, 위 상태가 "송출 중"인지 확인
  • 노래할 때 MR·게임 소리가 작아짐: mmsys.cpl → [통신] 탭 → "아무 작업도 안 함"
  • 다른 통화 프로그램 마이크가 이상해짐: 녹음 탭에서 원래 마이크를 다시 "기본 통신 장치로 설정" (노래할 때만 바꿔도 돼요)
  • CABLE이 안 보임: VB-Cable 설치 후 PC 재시작 → 이 창 새로고침
  • 내 목소리가 헤드폰으로 안 들림: 위쪽 "🎧 듣는 곳"이 실제 헤드폰인지 확인하고 아니면 [바꾸기], 장치 설정의 "내 목소리 듣기"가 켜져 있는지 확인
  • VB-Cable 설치 후 PC 소리가 다 안 들림: 작업 표시줄 🔊 → 출력 장치를 헤드폰으로 (VB-Cable이 기본 스피커를 바꿔 놓은 것)
  • 스테레오 믹스가 목록에 없음: Realtek 드라이버 설치 방법 보기
  • 스테레오 믹스로 아무것도 안 나감: 헤드폰이 메인보드 단자에 꽂혀 있고, 장치 설정의 헤드폰이 Realtek인지 확인
  • 목소리가 깨짐: 고음 보호 켜기, 빨간 경고가 뜨면 마이크 게인 낮추기
  • 하울링(삐-): 스피커 대신 헤드폰

도움이 됐다면 후원으로 응원해 주세요 🙏
