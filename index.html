⬇ VB-Cable 다운로드 📖 설치 방법
설치 없이 쓰기 (스테레오 믹스)

Win+R → mmsys.cpl → [녹음] 탭 → 빈 곳 우클릭 "사용 안 함 장치 표시" → "스테레오 믹스" 우클릭 → 사용 → 이 창 새로고침(F5)

스테레오 믹스로 송출 중
오버워치 음성 입력을 스테레오 믹스로 바꾸세요. 헤드폰 소리가 그대로 나가서 내 목소리도 함께 들려요.

헤드폰은 메인보드 단자(Realtek)에 꽂아야 해요. 게임·디스코드 소리도 같이 나가요.

오버워치 설정
  1. 옵션 → 사운드 → 음성 채팅 입력 → CABLE Output (스테레오 믹스 모드면 스테레오 믹스)
  2. 그룹/팀 음성 채팅 → 항상 켜기
  3. 노래가 끝나면 입력을 원래 마이크로 되돌리기

도움이 됐다면 후원으로 응원해 주세요 🙏
