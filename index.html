🎤 MR 리버브 송출기

마이크 + 리버브 + MR을 섞어서 오버워치 음성채팅으로 보냅니다.

스테레오 믹스 모드로 동작 중이에요. 설치 없이 송출돼요. 오버워치 음성 입력 장치를 스테레오 믹스로 바꾸세요.
헤드폰으로 들리는 소리가 그대로 송출돼서 내 목소리도 함께 들려요. 헤드폰을 스테레오 믹스와 같은 사운드카드(보통 Realtek, 메인보드 단자)에 꽂아야 해요.
송출할 장치가 없어요. 둘 중 하나가 필요해요.
① 스테레오 믹스 켜기 (설치 없음): Win+R → mmsys.cpl → [녹음] 탭 → 빈 곳 우클릭 "사용 안 함 장치 표시" → "스테레오 믹스" 우클릭 → 사용 → 이 창 새로고침(F5)
② VB-Cable 설치: 공식 페이지 열기 → Windows용 다운로드 → 압축 풀기 → VBCABLE_Setup_x64.exe 우클릭 "관리자 권한으로 실행" → Install Driver → PC 재시작 → 이 창 새로고침(F5)
VB-Cable은 VB-Audio(www.vb-cable.com)의 기부웨어입니다.
이 브라우저에서는 일부 기능이 동작하지 않아요. 크롬 또는 엣지로 열어 주세요. (유튜브 탭 MR, 헤드폰 장치 선택 미지원)
송출 준비 중…

MR

💡 스테레오 믹스 모드에서는 유튜브 MR을 그냥 재생하면 그대로 송출돼요. (볼륨은 유튜브에서 조절)

  1. 크롬에서 유튜브 MR 영상을 미리 열어 두기
  2. 위 버튼 → "Chrome 탭"에서 그 탭 선택
  3. "탭 오디오도 공유" 체크 → 공유
  4. 재생·일시정지·구간 이동은 유튜브 탭에서 하면 됩니다

⚠ 유튜브는 이 송출기와 같은 브라우저에서 열어야 탭 목록에 보여요. (송출기가 엣지로 열렸다면 유튜브도 엣지에서)

스피커를 쓰면 하울링이 날 수 있어요. 헤드폰을 쓰세요.

오버워치 설정 방법
  1. 옵션 → 사운드 → 음성 채팅 장치: 입력을 CABLE Output 으로 (스테레오 믹스 모드면 스테레오 믹스)
  2. 그룹/팀 음성 채팅 모드를 항상 켜기(오픈 마이크) 로
  3. 팀원에게 MR이 너무 크면 위의 MR 슬라이더를 낮추세요

무료로 쓰고 계신가요? 도움이 됐다면 후원으로 응원해 주세요 🙏

🔒 마이크 소리는 내 PC 안에서만 처리되며 어디에도 저장·전송되지 않습니다.

가상 마이크는 VB-Audio의 VB-CABLE(기부웨어)을 사용합니다. 이 사이트는 VB-Audio와 관련이 없습니다.
