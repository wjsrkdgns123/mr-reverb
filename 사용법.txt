MR 리버브 송출기
================
마이크에 리버브를 넣고 MR과 섞어서 오버워치 음성채팅으로 보내는 프로그램입니다.

사이트 : https://wjsrkdgns123.github.io/mr-reverb/

[처음 한 번만]
1. 크롬 또는 엣지로 사이트 열기 → 마이크 "허용"
2. (선택) 위쪽 [💻 바탕화면 앱으로 설치] → 설치 : 바탕화면 아이콘으로 바로 실행
3. 송출 장치 준비 (사이트가 자동으로 확인해서 안내해 줍니다)
   - 스테레오 믹스가 있으면 설치 없이 사용
   - 없거나 PC 소리 없이 깔끔하게 보내려면 VB-Cable(가상 마이크) 설치 → PC 재시작
4. 오버워치 설정
   - 옵션 → 사운드 → 음성 채팅 장치 "입력" : CABLE Output (스테레오 믹스 모드면 스테레오 믹스)
   - 그룹/팀 음성 채팅 : 항상 켜기(오픈 마이크)
   - 노래가 끝나면 입력 장치를 원래 마이크로 되돌리기!

[사용]
1. 사이트(또는 바탕화면 앱) 실행 → 화면을 한 번 클릭하면 소리가 켜집니다
2. MR 고르기 (둘 중 하나)
   - 🎵 파일 : MR 파일을 창에 끌어다 놓기 → ▶ (스페이스바로도 재생/정지)
   - ▶ 유튜브 탭 : 크롬에서 유튜브 MR 영상을 열어 두고 → [유튜브 탭 연결하기]
     → "Chrome 탭"에서 그 탭 선택 → "탭 오디오도 공유" 체크 → 공유
     → 재생/일시정지는 유튜브 탭에서
3. 슬라이더로 내 목소리 / MR / 리버브 조절, 방·홀·성당 중 선택
   설정은 자동 저장됩니다.

[VB-Cable 없이 쓰기 : 스테레오 믹스 모드]
- PC에 "스테레오 믹스"(주로 Realtek 사운드)가 있으면 VB-Cable 없이 자동으로 이 모드가 됩니다.
- 꺼져 있으면: Win+R → mmsys.cpl → [녹음] 탭 → 빈 곳 우클릭 "사용 안 함 장치 표시"
  → "스테레오 믹스" 우클릭 → 사용
- 오버워치 음성 입력 장치 : 스테레오 믹스
- 헤드폰은 스테레오 믹스와 같은 사운드카드(보통 메인보드 단자)에 꽂아야 합니다.
- 헤드폰 소리가 그대로 송출되므로 게임 소리·팀원 목소리도 함께 나갈 수 있습니다.

[브라우저]
- 크롬 또는 엣지에서 사용하세요. (웨일·브레이브 등 크롬 계열도 대부분 동작)
- 파이어폭스는 유튜브 탭 MR이 지원되지 않습니다.
- 유튜브 MR 탭은 송출기와 "같은 브라우저"에서 열어야 합니다.

[문제 해결]
- 팀원에게 안 들림 : 장치 설정의 "송출"이 CABLE Input 인지, 오버워치 입력이 CABLE Output 인지 확인
- 내 목소리가 안 들림 : 장치 설정에서 마이크와 헤드폰이 맞는지 확인
- 하울링(삐-) : 스피커 대신 헤드폰 사용
- MR이 너무 큼 : 팀원 귀를 위해 MR 슬라이더를 목소리보다 낮게

VB-Cable 은 VB-Audio(www.vb-cable.com)의 기부웨어입니다.
