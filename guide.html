📖 사용법

처음 한 번만 준비하면 다음부터는 송출기를 열고 MR만 틀면 돼요. (약 3분)

1. 송출 방법 고르기 (둘 중 하나)

송출기 소리를 오버워치로 넘겨줄 "마이크 자리"가 필요해요.

A. 스테레오 믹스 설치 없음

헤드폰으로 들리는 소리가 그대로 나가요. 쉽지만 게임·디스코드 소리도 같이 나가요.

  1. 소리 설정 열기
    Win+R → mmsys.cpl 입력 → Enter → 위쪽 [녹음] 탭
  2. 상태 확인
    목록에 안 보임꺼져서 숨겨진 상태 → 3번으로
    회색 아이콘 · 사용 안 함꺼져 있음 → 4번으로
    준비✅ 켜져 있음 → 5번으로
    기본 장치⚠ 켜져 있지만 다른 프로그램의 기본 마이크가 됨 → 원래 마이크를 우클릭해 "기본 장치로 설정"
  3. 숨은 장치 보이게 하기
    목록 빈 곳 우클릭 → 사용 안 함 장치 표시 체크
  4. 켜기
    스테레오 믹스 우클릭 → 사용
    ⚠ "기본 장치로 설정"은 누르지 마세요. 디스코드 등이 PC 소리를 마이크로 보내게 돼요.
  5. 헤드폰 연결
    헤드폰을 메인보드 단자(Realtek)에 꽂아요. 스테레오 믹스는 그 단자로 나가는 소리만 녹음해요.
    확인: 유튜브를 틀었을 때 "스테레오 믹스" 옆 초록 막대가 움직이면 정상
  6. 송출기 새로고침
    송출기에서 F5 → 자동으로 스테레오 믹스 방식이 선택돼요.

목록에 스테레오 믹스가 아예 없으면 Realtek 사운드 드라이버가 없거나 오래된 거예요 → 아래 A-1로 드라이버를 설치해 보세요.

A-1. 스테레오 믹스가 없을 때: Realtek 드라이버 설치 무료

Windows가 자동으로 깔아 준 기본 드라이버에는 스테레오 믹스가 없는 경우가 많아요. 제조사 드라이버를 깔면 생기는 경우가 많아요.

  1. Realtek 사운드가 있는지 확인
    Win+X → 장치 관리자 → 사운드, 비디오 및 게임 컨트롤러 펼치기
    Realtek(R) Audio 또는 Realtek High Definition Audio✅ 있음 → 2번으로
    "High Definition Audio 장치"만 있음Realtek 칩은 있지만 Windows 기본 드라이버 → 2번으로
    USB 헤드셋·오디오 인터페이스만 있음메인보드 사운드가 없거나 꺼져 있어요 → B. VB-Cable을 쓰세요
  2. 내 PC 모델 확인
    Win+R → msinfo32 → Enter
    • 조립 PC(데스크톱): BaseBoard 제조업체와 BaseBoard 제품 (예: ASUS · TUF GAMING B550-PLUS)
    • 노트북·브랜드 PC: 시스템 제조업체와 시스템 모델
  3. 제조사 사이트에서 오디오 드라이버 받기
    모델명을 검색 → 드라이버 → Audio(Realtek) 받기
    메인보드 ASUS MSI GIGABYTE ASRock
    노트북·PC 삼성 LG HP Dell Lenovo ASUS
  4. 설치하고 PC 재시작
    받은 파일을 실행해 설치 → 재시작 → 위 A의 1번부터 다시 확인
  5. 제조사 드라이버가 없으면
    • 설정 → 업데이트 및 보안 → Windows 업데이트 → 선택적 업데이트 보기 → 드라이버 업데이트에 Realtek이 있으면 설치
    • 마지막 방법: Realtek 공식 범용 드라이버 (오래된 버전이라 최신 PC에는 설치가 안 될 수 있어요)

⚠ 드라이버는 꼭 위 공식 사이트에서만 받으세요. "드라이버 자동 설치" 프로그램이나 모음 사이트는 광고·악성코드가 섞여 있는 경우가 많아요.

드라이버를 깔아도 스테레오 믹스가 안 생기는 PC도 있어요(제조사가 기능을 빼 둔 경우). 그때는 B. VB-Cable을 쓰세요.

B. VB-Cable 한 번 설치

송출기 소리만 깔끔하게 나가요.

  1. 다운로드
    ⬇ VB-Cable 다운로드 (공식) 공식 페이지
  2. 압축 풀기
    받은 zip 우클릭 → 압축 풀기
    ⚠ zip 안에서 바로 실행하면 설치가 안 돼요.
  3. 관리자 권한으로 실행
    VBCABLE_Setup_x64.exe 우클릭 → 관리자 권한으로 실행 → 예
    32비트 Windows라면 VBCABLE_Setup.exe
  4. Install Driver → 완료 창이 뜰 때까지 기다리기
  5. PC 재시작
  6. 송출기 새로고침 → 송출 장치가 CABLE Input으로 자동 선택돼요.

2. 오버워치 설정

  • 옵션 → 사운드 → 음성 채팅 입력 장치 → A면 스테레오 믹스, B면 CABLE Output
  • 그룹·팀 음성 채팅 → 항상 켜기(오픈 마이크)

3. ⚠ 노래가 끝나면

오버워치 음성 입력 장치를 원래 마이크로 되돌려 주세요.
안 되돌리면 B는 팀원에게 아무 소리도 안 들리고, A는 내 목소리 대신 PC 소리만 들려요.

문제 해결

  • 팀원에게 안 들림: 오버워치 입력 장치 확인, 송출기 위쪽이 "송출 중"인지 확인
  • 송출기에 CABLE이 안 보임: PC 재시작 후 송출기 새로고침(F5)
  • 스테레오 믹스로 아무것도 안 나감: 헤드폰이 메인보드 단자에 있는지, 송출기 장치 설정의 헤드폰이 Realtek인지
  • 목소리가 깨짐: 송출기의 고음 보호 켜기, 빨간 경고가 뜨면 마이크 게인 낮추기
  • 하울링(삐-): 스피커 대신 헤드폰

VB-Cable 지우기

설치할 때 쓴 VBCABLE_Setup_x64.exe를 다시 관리자 권한으로 실행 → Remove Driver → PC 재시작

VB-Cable은 VB-Audio(www.vb-cable.com)의 기부웨어입니다. 이 사이트는 VB-Audio와 관련이 없습니다.
