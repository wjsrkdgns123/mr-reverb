📖 VB-Cable 설치 매뉴얼

VB-Cable은 송출기 소리를 오버워치로 넘겨주는 "가상 마이크"예요. 처음 한 번만 설치하면 됩니다. (약 3분)

설치 순서

  1. VB-Cable 다운로드
    ⬇ VB-Cable 다운로드 (공식) 공식 페이지
    다운로드가 안 되면 공식 페이지에서 Windows용 "Download"를 누르세요.
  2. 압축 풀기
    받은 VBCABLE_Driver_Pack45.zip 우클릭 → "압축 풀기" (또는 "모두 압축 풀기")
    ⚠ zip 안에서 바로 실행하면 설치가 안 돼요. 꼭 압축을 먼저 푸세요.
  3. 관리자 권한으로 실행
    풀린 폴더에서 VBCABLE_Setup_x64.exe 우클릭 → "관리자 권한으로 실행" → "예"
    32비트 Windows라면 VBCABLE_Setup.exe
  4. Install Driver 클릭
    창이 뜨면 "Install Driver" → 설치 완료 창이 뜰 때까지 기다리기
    중간에 창이 멈춘 것처럼 보여도 기다리면 됩니다.
  5. PC 재시작
    재시작해야 설치가 마무리돼요.
  6. 송출기 열기
    송출기를 열면 송출 장치가 CABLE Input으로 자동 선택되고, 위쪽에 "송출 중"이 떠요.
    안 바뀌면 [장치 설정] → 송출 방식 "가상 마이크" → 송출에서 CABLE Input 선택
  7. 오버워치 설정
    • 옵션 → 사운드 → 음성 채팅 장치 입력 → CABLE Output
    • 그룹/팀 음성 채팅 → 항상 켜기(오픈 마이크)

⚠ 노래가 끝나면

오버워치 음성 입력 장치를 원래 마이크로 되돌려 주세요.
CABLE Output으로 둔 채 송출기를 닫으면 팀원에게 내 목소리가 안 들려요.

설치 없이 쓰기: 스테레오 믹스

PC에 "스테레오 믹스"(주로 메인보드 Realtek 사운드)가 있으면 VB-Cable 없이도 송출돼요.
  • 켜기: Win+R → mmsys.cpl → [녹음] 탭 → 빈 곳 우클릭 "사용 안 함 장치 표시" → "스테레오 믹스" 우클릭 → 사용
  • 오버워치 입력 장치: 스테레오 믹스
  • 헤드폰은 같은 사운드카드(메인보드 단자)에 연결
헤드폰으로 나오는 소리가 그대로 송출돼서 게임 소리·디스코드 소리도 같이 나가요. 송출기 소리만 깔끔하게 보내려면 VB-Cable을 쓰세요.

문제 해결

  • 팀원에게 안 들림: 송출기 송출 = CABLE Input, 오버워치 입력 = CABLE Output 인지 확인
  • 송출기에 CABLE이 안 보임: PC 재시작 후 송출기 새로고침(F5)
  • 내 목소리가 깨짐: 송출기의 🛡 고음 보호 켜기, 빨간 경고가 뜨면 마이크 게인 낮추기
  • 하울링(삐-): 스피커 대신 헤드폰 사용

VB-Cable 지우기

설치할 때 쓴 VBCABLE_Setup_x64.exe를 다시 관리자 권한으로 실행 → "Remove Driver" → PC 재시작

VB-Cable은 VB-Audio(www.vb-cable.com)의 기부웨어입니다. 이 사이트는 VB-Audio와 관련이 없습니다.
